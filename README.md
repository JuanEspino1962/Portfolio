# Portfolio

Portfolio responsive desarrollado a partir de un diseño de referencia, con especial atención a la fidelidad visual, la semántica HTML, la accesibilidad y el comportamiento responsive.

## Características

- Diseño responsive para Mobile, Tablet y Desktop.
- Estados interactivos Desktop Active.
- HTML semántico.
- SASS como preprocesador CSS.
- Webpack para desarrollo y build de producción.
- Estados hover y focus-visible.
- Formulario de contacto con validación visual personalizada.
- Overlay interactivo en las tarjetas de proyectos.
- Iconos SVG y recursos gráficos optimizados para cada breakpoint.

## Tecnologías utilizadas

- HTML5
- CSS3
- SASS
- JavaScript
- Webpack
- Git
- GitHub
